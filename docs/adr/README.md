# docs/adr/ — Architecture Decision Records

Uma decisão por arquivo: `ADR-NNN-titulo.md`, com **contexto, decisão, consequências, riscos e alternativas descartadas** (`CLAUDE.md`).

## Regras

- **Número nunca é reaproveitado.**
- **ADR aceita não é editada para mudar de ideia.** Decisão nova recebe número novo e marca a anterior como *Substituída por ADR-NNN*.
- **ADR é do Cowork**, escrita direto na `main`. O Code **propõe** ADR pela PR quando a implementação exigir decisão estrutural; quem aceita é o PI.
- **Discordar de ADR aceita não é achado de revisão** — é proposta de ADR nova ([`REVIEW.md`](../REVIEW.md) §5).
- O índice vive em [`DECISIONS.md`](../DECISIONS.md).

## Status possíveis

`Proposta` · `Aceita` · `Substituída por ADR-NNN` · `Revogada`
