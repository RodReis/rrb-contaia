## Brand & Style

This design system embodies the precision, security, and computational depth required by mission-critical financial engineering and automated tax compliance platforms. Built around an ultra-refined dark carbon aesthetic, the visual direction projects absolute analytical authority, mathematical rigor, and real-time execution.

The aesthetic philosophy draws heavily from modern technical minimalism, utilizing deep obsidian layers, crisp optical contrasts, structured micro-borders, and targeted spectral accents. Instead of purely cosmetic ornamentation, color serves an informational mandate: cyan highlights active execution and structural telemetry, emerald confirms reconciliation integrity (R$ 0,00 delta parity), and amber signals regulatory scrutiny. The user interface creates an environment of calm focus, high legibility under dense telemetry, and razor-sharp data hierarchy.

## Colors

The palette establishes an obsidian-carbon continuum engineered specifically to eliminate eye fatigue during intensive auditing workflows while maintaining AAA-grade contrast ratios for quantitative readouts.

### Core Canvas & Surfaces
- **Canvas Base (`#090d16`):** Deep Obsidian Carbon. Serves as the bedrock viewport layer.
- **Surface Low (`#0c1220`):** Recessed canvas tone for docked sidebars and structural rails.
- **Surface Container (`#0f172a`):** Carbon Slate. The default substrate for modules, panels, and analytical sections.
- **Surface Container High (`#182234`):** Elevated carbon card tone for interactive surfaces, active rows, dialogs, and popovers.
- **Surface Highlight / Overlay (`#1e293b`):** Focus states, hover overlays, and segmented control backgrounds.

### Borders & Structural Lines
- **Border Subtle (`#1e293b`):** Primary boundary line for cards, grid partitions, and table divisions.
- **Border Muted / Active (`#334155`):** Secondary structural rule for interactive boundaries, hover outlines, and distinct component groupings.

### Typography & Content
- **Text Primary (`#f8fafc`):** Pure Slate White. Dedicated to principal KPIs, monetary amounts, primary headlines, and active field entries.
- **Text Secondary (`#94a3b8`):** Muted Slate. Used for secondary metadata, column headers, input labels, and structural breadcrumbs.
- **Text Tertiary / Disabled (`#64748b`):** Timestamp indicators, unselected tabs, and inactive controls.

### Functional Accents
- **Primary / Brand Cyan (`#38bdf8`):** Electric Cyan / Carbon Ice. Indicates active operations, interactive links, primary actions, and focused metrics.
- **Success / Compliance Emerald (`#10b981`):** Emerald Mint. Dedicated to fiscal compliance, successful ledger settlement, positive deltas, and zero-error audit runs.
- **Warning / Alert Amber (`#f59e0b`):** Regulatory discrepancy, validation alert, pending authorization, or tax threshold limits.
- **Critical / Discrepancy Crimson (`#f43f5e`):** Divergence, failed validation, calculation error, or compliance breach.

## Typography

The typographic hierarchy pairs **Geist** for display, structural headlines, numerical readouts, and UI control elements with **Inter** for sustained linear reading and dense data descriptions.

All financial balances, tax keys, transaction IDs, and currency amounts utilize tabular lining figures (`font-variant-numeric: tabular-nums;`) to ensure razor-sharp vertical alignment across analytical ledgers and grid views. Uppercase micro-labels leverage a subtle positive letter-spacing (`letter-spacing: 0.04em`) to maintain sharp character distinction on high-DPI screens.

## Layout & Spacing

The layout philosophy is built on an enterprise-grade fluid grid calibrated for maximum information density without visual crowding. A standard 12-column grid structure underpins analytical desktops, transitioning to 8 columns on tablets and 4 columns on mobile viewports.

The layout operates on a compact 4px base increment. Data tables and enterprise lists adopt high-density compact paddings (`space-xs` and `space-sm`), while top-level structural containers and analytical KPI groupings leverage `space-lg` to separate functional domains. Margin safety zones adapt systematically across viewports to preserve scanability during deep analytical sessions.

## Elevation & Depth

In this carbon system, elevation is conveyed through **tonal stacking** and **precise structural borders** rather than soft, expansive blur shadows. Deep obsidian surfaces recede, while cards and interactive controls elevate through brighter slate luminance and hairline rim illumination.

- **Level 0 (Base Canvas):** `#090d16` with no border.
- **Level 1 (Section Panels / Static Containers):** `#0f172a` framed by a 1px solid `#1e293b` border.
- **Level 2 (Cards / Interactive Widgets):** `#182234` framed by a 1px solid `#334155` border, augmented with a subtle directional top-edge highlight (`box-shadow: inset 0 1px 0 0 rgba(255, 255, 255, 0.05)`).
- **Level 3 (Overlays / Modals / Context Flyouts):** `#182234` with an ambient dark rim (`0 20px 25px -5px rgba(0, 0, 0, 0.7), 0 8px 10px -6px rgba(0, 0, 0, 0.7)`) and a 1px perimeter border of `#38bdf8` at 20% opacity.

Glows are restricted to purposeful, low-radius micro-flairs: active inputs and status indicator dots receive an accent-tinted bloom of 0 0 12px with 25% opacity in either Electric Cyan or Emerald Mint.

## Shapes

The design system maintains a structured, surgical geometry. A disciplined low-radius scale is enforced throughout:

- **Base Radius (0.25rem / 4px):** Standard micro-elements, status chips, input steppers, table-row highlight segments, and inline code pills.
- **Medium / Card Radius (0.5rem / 8px):** Primary cards, data modules, modal panels, form inputs, dropdown listboxes, and action buttons.
- **Large Radius (0.75rem / 12px):** Root application shells, global overlays, and standalone dashboards.

This calibrated soft-corner geometry keeps data-heavy grids crisp, eliminates excess perimeter whitespace, and preserves tabular alignment.

- Built on `#182234` with 1px border `#1e293b`.
- Internal padding adheres to `space-md` for high-density telemetry or `space-lg` for executive summary summaries.
- Header bars feature an inline bottom divider of 1px solid `#1e293b` separating metric titles from raw data streams.

- Invalid state: border `#f43f5e`, focus ring `rgba(244, 63, 94, 0.25)`.

- **Pending Review:** Background `rgba(245, 158, 11, 0.1)`, text `#f59e0b`, border `rgba(245, 158, 11, 0.25)`.
- **Informational / Telemetry:** Background `rgba(56, 189, 248, 0.08)`, text `#38bdf8`, border `rgba(56, 189, 248, 0.2)`.

### Tables & Data Grids
- **Header:** Background `#0f172a`, text `#94a3b8`, 11px uppercase `label-sm`, bottom border 1px solid `#334155`.
- **Rows:** Alternating transparent and `#090d16` base. Hover state: `#182234`. Dividing border: 1px solid `#1e293b`.
- **Numeric Cells:** Rendered strictly with `tabular-nums` in `Geist`, aligned right with currency tags in `#64748b`.

### Checkboxes & Radios
- Size: 16x16px, background `#0f172a`, border 1px solid `#334155`, radius 4px (checkbox) or circle (radio).
- Checked: background `#38bdf8`, border `#38bdf8`, icon `#090d16`. Focus outline: 2px offset in `#090d16`.
